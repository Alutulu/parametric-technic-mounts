# Parametric Technic Mounts

**Parametric 3D-printable mounts for LEGO® Technic™ compatible parts.**

This repository contains OpenSCAD scripts to generate custom LEGO-compatible parts for electronics and other components. All models are fully parametric, allowing you to easily adjust dimensions, hole patterns, and features for your specific needs. The geometry is based on expired LEGO patents and is designed to be compatible with official LEGO Technic™ elements.
